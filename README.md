# Detective: Solve the Mystery — Browser Edition

This is the Streamlit browser version of the original Tkinter game.

## Run on your computer
1. Install Python.
2. Open a terminal in this folder.
3. Run: `python -m pip install -r requirements.txt`
4. Run: `python -m streamlit run streamlit_app.py`

## Publish a public link with Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `streamlit_app.py`, `requirements.txt`, and the entire `assets` folder.
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Choose **Create app**, select your repository, and set the main file to `streamlit_app.py`.
5. Click **Deploy**. Streamlit will provide your public app link.

The app uses Streamlit's built-in interface components; it does not use HTML, CSS, Pygame, or Arcade.
